# Recipe Deck

レシピ本文を平文のまま保存し、10点評価・最大3つのタグ・キーワードで探せる個人用PWAです。データは端末のIndexedDBに保存され、外部へ自動送信しません。

## 使い方

- 「レシピを追加」で本文を入力すると自動保存されます。最初の空行でない行がタイトルです。
- 評価7点以上は「また食べたい」。キーワード、最低評価、複数タグのAND条件で絞り込めます。
- 編集画面からレシピ全文と評価、備考などをAI質問用にコピーできます。
- 「出力」で全件・検索結果・指定条件のAI用JSONをコピーまたはダウンロードできます。
- 「完全バックアップ」で復元用JSONを保存してください。保存後の確認操作を終えると、バックアップ日時が記録されます。インポートは検証・確認後に端末内データを丸ごと置き換えます。

**大切な注意:** ブラウザーのサイトデータ削除や機種変更でIndexedDBは失われる可能性があります。完全バックアップJSONを定期的に端末外へ保管してください。AI用JSONは復元には使えません。アプリは初回読み込み後オフラインでも使えます。

公開URL: https://yuuuh26.github.io/recipe-deck/

## 開発

静的ファイルのみで動作します。ローカルではHTTPサーバーで配信してください（例: `python3 -m http.server 8000`）。`npm test` でデータ変換とバックアップ検証を確認できます。
